About this method
{% if method == "Maximum Sharpe Ratio" %}

Goal: Find the portfolio with the highest risk-adjusted return.

Maximises the ratio of excess return (above risk-free rate) to volatility.

\( SR = \frac{E[R_p] - R_f}{\sigma_p} \)

Best for: Investors seeking the most efficient risk-return trade-off.

{% elif method == "Minimum Variance" %}

Goal: Find the portfolio with the lowest possible volatility.

Minimises portfolio standard deviation through diversification.

\( \min \sqrt{w^T \Sigma w} \)

Best for: Conservative investors prioritizing stability.

{% elif method == "Minimum CVaR" %}

Goal: Minimize expected losses in worst-case scenarios.

Minimises Conditional Value at Risk using Rockafellar-Uryasev LP formulation.

\( \min\; CVaR_\alpha = E[L \mid L > VaR_\alpha] \)

Best for: Risk-averse investors focused on tail risk.

{% elif method == "Mean-CVaR Trade-off" %}

Goal: Balance expected return against tail risk.

Optimises weighted combination: min(−E[R] + λ·CVaR).

\( \min \; -E[R] + \lambda \cdot CVaR_\alpha \)

Best for: Investors who want explicit control over risk-return preferences.

{% elif method == "Maximum Return (Constrained)" %}

Goal: Maximize expected return within a risk budget.

Finds highest-return portfolio subject to volatility or CVaR constraint.

\( \max E[R] \;\; \text{s.t.} \;\; \sigma \leq \sigma_{max} \)

Best for: Portfolio managers with regulatory or mandate-driven risk limits.

{% elif method == "Exponential Utility (CARA)" %}

Goal: Optimize using theoretically grounded risk-aversion model.

Maximises expected CARA utility. Based on Elton & Gruber Chapter 10.

\( \max E[U] = E[-e^{-C \cdot 50 \cdot R}] \)

Best for: Quantitative investors with well-defined risk preferences.

{% endif %}
